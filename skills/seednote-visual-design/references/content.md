## 内容页设计规范

**内容密度**：
- 文字占比：20-35%
- 每页字数：≤60 字
- 每页信息点：2-4 个，每点 ≤15 字
- 留白：35-45%

**6 种布局模式**（按内容类型选）：
1. **编号清单** — 步骤、要素列举
2. **对比双栏** — Before/After，优劣对比
3. **步骤流程** — 有先后顺序的操作
4. **标注图解** — 图片+手绘说明
5. **数据卡片** — 数字/数据展示
6. **Q&A 对话** — 问答式知识

**视觉规范**：
- 字体：圆角/手写，避免黑体/等线
- 高亮方式：色块或荧光线标记，勿加粗
- 背景：有真实物理关系的场景，或按共享风格块指定的插画/水彩/纸面媒介；多张内容图仍需保持场景或媒介构图有变化
- 批注：手绘风格，与封面保持一致
- 色调：与封面统一
- 中文主题只允许出现简体中文；禁止英文翻译、拼音、乱码、伪词和自动补充外文标签
- 当页文字必须来自 image-plan 的"必须出现文字"，不得自行创造新术语或改写关键数字

**视觉多样性**（多张内容图时，2~3 张均适用）：
- 3+ 种不同实景背景
- 构图角度变化（正视/俯视/局部特写）
- 焦点位置错落（左/中/右交替）
- 批注样式轮换（不完全重复同一种）

**禁止**：
- 3D 渲染/纯色大背景
- PPT 式对称布局
- 科学海报风格
- 无结构文字墙
- 连续 3 张相同视觉元素
- 手机框/设备框
- 与当页主题无关的茶类、季节或产品
- 误导性冲泡动作，例如把"10秒出汤"写成"焖泡10秒"

## 图片内容规划（image-plan.md）

基于选题方向、最终标题和目标受众，在生成图片前先独立规划每张图的具体内容，写入 `output/image-plan.md`。

**图片总数**：1~5 张，由 `seednote_image_mode` 决定：`cover_only` 仅封面，`cover_content` 为封面 + 内容图，`cover_tail` 为封面 + 尾图，`full` 为封面 + 内容图 + 尾图。封面始终生成；内容图仅在 `cover_content` / `full` 模式生成，张数按信息点分组自适应（最多 3 张）；尾图仅在 `cover_tail` / `full` 模式生成，不含尾图的模式 `image-plan.md` 不含 `## tail` 节。所有图片逐张调用 `generate_image` 生成。

封面、内容图和尾图均不预设是否使用任务上传图片。每页根据 `image-plan.md` 独立选择 0、1 或多张任务原图；没有相关任务参考时使用纯文生图。项目风格图只使用分析得到的文本风格块，原图路径不得进入生成调用。

**格式模板**：

```markdown
# 图片内容规划

## 总体策略

- 主题方向: xxx
- 目标受众: xxx
- 图片内容定位: xxx
- 计划图片数量: N 张

---

## cover 封面

- 钩子: （≤10字）
- 辅助信息: （≤15字）
- 必须出现文字: （1-2 行简体中文主文案）
- 视觉主体: （能直接看出主题的实物/场景）
- 禁止元素: （英文、伪词、错别字、无关品类、医疗功效承诺）
- 验收标准: （0.5 秒内能读懂主题）

---

## image_01 [内容] 主题：xxx

- 信息点1: （8-15字）
- 信息点2: （8-15字）
- 推荐布局: 编号清单 / 对比双栏 / 步骤流程 / 标注图解
- 必须出现文字: （2-4 条简体中文短句）
- 视觉主体: （当页知识对应的实物/过程/对比对象）
- 禁止元素: （英文、伪词、无关主题、误导性参数）
- 验收标准: （文字准确 + 主体准确 + 与 image-plan 一致）

---
```

## Prompt 模板（v3 - 结构化中文文字渲染）

生成前先读 [prompt-blueprint.md](prompt-blueprint.md)。下面的模板是内容图的默认编译顺序，不是把所有字段原样填成形容词清单；`image-plan.md` 明确指定的媒介、布局、文字和禁止项优先。

**内容页**：
```
页面契约：这是种草笔记信息流的内容图，页面职责是「{page_goal}」，页面主题是「{topic}」，输出比例为 {aspect_ratio}。

文字契约 — 只允许出现以下可见文字：
{visible_text_whitelist}
以上文字必须按阅读顺序逐条、原样渲染，禁止合并、拆分、改字、改标点或同义改写。计划要求可见的徽章字/步骤字必须单独列在白名单内；模板中的列表编号只是元指令，不能被画进图片。
文字布局：{text_layout}；文字安全区：{text_zone}；保证缩略图可读，主体和装饰不得遮挡文字。

构图地图：{camera}，{shot}；第一视觉焦点是 {focal_area}；{layout_map}；保留 {negative_space}；阅读顺序为 {reading_order}。

主体事实：必须出现 {visual_subject}；对象状态为 {subject_states}；每条信息点分别对应 {subject_relations}；只表现 {allowed_action}。

艺术指导：{medium_and_surface}；共享风格锚点为 {style_anchors}；本页变化为 {page_variation}；批注/图标语言为 {annotation_language}。

光线与质感：{lighting}；强调 {material_details}；保持主体边缘清楚、茶汤/纸面/器具的材质可辨。

禁止项：{negative_constraints}；禁止任何未列入白名单的中文、英文字母、拼音、阿拉伯数字、乱码、伪词、水印、品牌名或装饰标语；禁止把其他页面的信息、茶类或季节带入本页；禁止纯色大背景、PPT 对称布局、3D 渲染、设备框和误导性动作。

输出验收：{acceptance_criteria}；文字内容、顺序、主体关系、布局和风格必须同时满足，缩小到信息流卡片仍可读，无水印、无额外文字。
```

**生成方式（逐张调用 generate_image）**：

按 `image-plan.md` 逐张调用 `generate_image`：
- 每张使用对应 section 的页面职责、文字白名单、构图地图、主体状态/关系、媒介与光线和页面级禁止项填充模板；不要把整篇正文作为 `{full_outline}` 原样塞入 prompt
- `output_path` 设为 `output/image_01.png`、`output/image_02.png` ... `output/image_03.png`
- `ref_image_paths` 只包含 `image-plan.md` 为当前页选中的原始路径，顺序与 prompt 的参考图编号一致；当前页没有相关参考时省略该字段并使用纯文生图
- 每张使用独立视觉主体、场景、构图和参考子集，禁止与其他内容图机械复用
尾图单独生成见 tail.md（仅当 `seednote_image_mode` 包含尾图时）。

> **关键规则**：封面、内容图和尾图均不预设是否使用任务上传图片。每页根据 `image-plan.md` 独立选择 0、1 或多张任务原图；没有相关任务参考时使用纯文生图。项目风格图只使用分析得到的文本风格块，原图路径不得进入生成调用。每张内容图必须使用对应信息点构造独立 prompt；共享“风格延续：{style}”文本块只负责调性一致，不能替代对产品事实和参考素材用途的逐页判断。
