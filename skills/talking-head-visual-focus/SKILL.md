# 口播画面视觉焦点

本 Skill owns one question：口播画面里，非全屏素材应该放在哪里，谁先被看见，旧素材退到哪里，以及人物始终不能被挡住。

调用方仍拥有剪辑决策、素材权利判断和渲染执行；本 Skill 不调用 MCP，不拥有发布状态，不替代 OpenMontage 的能力检查。

需要具体坐标、槽位、尺寸和验收数值时读 [references/geometry.md](references/geometry.md)。需要对照状态机样例时读 [tests/layout-cases.json](tests/layout-cases.json)。

## 输入

- 成片画幅与冻结比例（`$VIDEO_ASPECT_RATIO`）。
- 每段口播的真实画面：人物是否在画内、头部包围盒、手部/产品/关键动作位置。
- 该段要展示的素材：类别（`live_video`、`image`、`motion_graphic`）、表达目的、是否全屏、素材内部的关键主体与文字位置。
- 字幕与平台安全区设置。

缺少头部位置或画幅时，先测量再排布；不得凭印象假设人脸在上三分之一。没有任何自动人脸/姿态检测能力时，按语义段抽帧目视标定头部包围盒，并把抽帧时间点、标定方法和不确定范围写入证据。

## 核心规则

1. **主位在黄金下位线。** 非全屏素材的默认视觉中心在画面高度约 61.8%（`y=0.618`，从顶部计），横向居中。这是指导线，`y` 可在 `0.56–0.68` 内按避让结果取最近的有效点。
2. **头部零遮挡。** 任何状态下，非全屏素材都不得压到头部包围盒，包括入场、出场和过渡帧。没有“遮一点点”的例外。头部不在画内时，必须记录“该段无头”这一事实，规则才暂时不适用。
3. **新素材先上位。** 每次出现新的或语义更重要的素材，它立即取得主位；旧素材同帧降级，不得与新主位同权重并列。
4. **层级必须可读。** 主位与次位在尺寸、对比、动效和叠放顺序上至少两项明显不同。两个等权焦点等于没有焦点。
5. **有理由才偏离。** 任何偏离默认锚点、降级、隐藏或退出，都写入视觉计划的理由字段；不写理由的偏离视为缺陷。

## 焦点状态机

按时间顺序处理同一段画面内的素材：

| 数量 | 主位 | 次位 |
|---|---|---|
| 1 | 该素材 | 无 |
| 2 | 新素材 | 第一个素材移到上方次位；上方不可用时移到安全的下方或侧向次位 |
| 3 | 第三个素材 | 上一个主位 → 次位一，最早的素材 → 次位二 |
| >3 | 最新且最重要的素材 | 只保留仍可读的次位；更早的素材缩小、降权或退出，并记录原因 |

过渡要求：新主位入场时，旧主位同步降级或退出。不接受“新素材淡入同时旧素材保持全强调”的并列状态。过渡的每一帧仍须通过头部避让检查。

## 全屏素材与人物内嵌

素材占满全画面、而人物存在感仍需保留时，用同步的圆形人物内嵌替代“人物消失”：

- 取同一时间码的真实人物画面做圆形裁切，保持口型同步，不用静帧。
- 圆形直径约为画面宽度的 `0.14–0.20`，上限 `0.22`；加 2–4% 宽度的描边环和轻微投影把人物与背景分开。
- 角位优先顺序：左上 → 右上 → 左下 → 右下；具体坐标、边距和避让见 references/geometry.md。
- 每段连续全屏只用一个角位，段内不跳角；只在段与段的边界做短促位移。
- 人物内嵌永远不是主焦点，对比度不得压过素材本身的关键内容。
- 四个角都会压住素材关键主体、文字或数据时，不要强行全屏：退回非全屏主次布局。
- 渲染能力不支持人物内嵌或圆形遮罩时，同样退回非全屏主次布局；不得因为工具限制就让全屏段丢掉人物，也不得用压住头部或压住素材内容的方式凑合。

## 避让优先级

发生冲突时按顺序解决，每一步都可写进证据：

1. 在黄金带内换到最近的有效锚点。
2. 缩小素材或人物内嵌。
3. 重新裁切或重排素材内部构图。
4. 把素材延后到人物不在画内的时段。
5. 退回非全屏布局或改用更少的素材。

不得为了保住预设坐标而压头部、压字幕、压产品，或让素材互相覆盖。

## 输出

在既有 `visual_plan.json` 的每个素材条目上记录（不新增 Adapter 字段）：

- `focus_role`：`primary` / `secondary_1` / `secondary_2` / `supporting` / `exiting`
- `focus_rank`、`scale_tier`、`z_order`
- `anchor`：归一化 `{x, y}`
- `head_safe` 与 `collision_targets`：本次避让的实际依据
- `transition_in` / `transition_out`
- 需要时 `demotion_reason`、`safe_area_decision`
- 全屏段额外记录 `speaker_inset`：模式、角位、直径、描边、稳定起点

## 自检

- [ ] 每一帧都能指出唯一的视觉中心，且它在黄金下位线附近。
- [ ] 任何入场、出场和过渡帧都没有覆盖头部、手部、产品或关键动作。
- [ ] 新素材出现的那一帧，旧素材已经降级。
- [ ] 三个以上素材时，画面没有退化成等权拼贴。
- [ ] 全屏段的圆形人物内嵌角位稳定，且没有压住素材的关键内容。
- [ ] 所有偏离默认锚点的决定都有文字理由。
