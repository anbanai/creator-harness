# Video Use

Use the image-installed `browser-use/video-use` helpers under `ANBAN_VIDEO_USE_ROOT` with the Server-provided transcription credential. Produce a transcript and semantic edit decisions under `output/`. Preserve meaning, order, qualifications, numbers, causality, natural emphasis, and uncertain speech. When a phrase may be intentional, keep it and record the uncertainty. Discover supported helper arguments from the installed helper's `--help`; record the helper and observed package/source revision in evidence when available, without making an exact revision a workflow requirement.

Use the runtime identity established by the owning Agent: complete Server task context is managed; a standalone local run requires an explicit `runtime_mode=local_test` input. Missing/partial managed context without that explicit declaration is a blocking failure. In managed mode, a missing helper, credential, or transcription capability is a blocking failure; do not fall back to local Whisper, a different ASR provider, or guessed timestamps. Local test mode must record the degradation in `output/progress-state.json` and may never be reported as managed success.

After transcript correction, run a duplicate-phrase audit before locking the EDL: detect repeated punctuation-stripped phrases of at least five Chinese characters within a segment and across adjacent segments, and maintain a configurable proper-noun glossary. Every ASR word whose duration is greater than 1.0 seconds must also be reviewed one by one by listening again or by an unprompted narrow-window re-transcription; this review is required even when the word is not a duplicate candidate. Record each word's review status, corrected text when applicable, keep/modify decision, rationale, and evidence path. After rendering, transcribe the independent final audio and run the same scan and long-word review. For homophone or recognition disputes, use a narrow 3–4 second window with an unprompted re-transcription; do not decide from `avg_logprob` or a prompt alone. A detected duplicate is a review candidate, not an automatic deletion: preserve intentional rhetorical repetition and record accepted/rejected decisions with evidence.

The managed image injects the upstream helper's expected `ELEVENLABS_API_KEY` environment variable from Server configuration. Do not print, copy, serialize, or otherwise expose it. Do not create an HTTP client, substitute another ASR provider, install temporary runtimes, or infer successful transcription from a file or process exit code. Verify the transcript content and report upstream/helper failures as a blocking failure state with a resume point.
