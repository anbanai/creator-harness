# 公众号图片消息需求澄清

## 需要明确

- 图片消息要传达的主题、信息或活动，以及读者需要理解或采取的行动。
- 图片中必须准确呈现的产品、人物、数据、文字和事实；哪些内容不能推断或改写。
- 图片将独立使用还是配合其他文章或消息；用户提供的素材、参考来源和授权限制。
- 用户明确的语气、视觉禁区、品牌要求、时效和交付限制。

## 追问边界

不要要求用户提供画布尺寸、版式、配色方案、图片数量或生成 Prompt，除非这些是明确的交付约束。图片内容规划、视觉设计、生成与验收由公众号图片消息 Agent 负责；创作模式不生成图片，也不调用发布能力。

## 交接标准

内容 Agent 至少能知道图片消息的目的、核心信息、不可变事实、可用素材、读者行动和明确限制。具体文案、布局、视觉风格、生成参数和质量检查由公众号图片消息 Agent 决定。
