# 内容优化实验参考

## 证据状态

- 来源：内部编辑经验；未取得平台公开、可复核的排序公式。
- 核验日期：未核验算法；2026-09-19 审计并移除年份背书、CES 权重和推荐保证。
- 适用范围：Seednote 原创/复刻内容的实验设计，不用于预测曝光或宣称平台规则。
- 失效策略：用户要求、当前平台提示和实测数据优先；无法验证的建议不得成为硬阻塞。上线前复查平台创作中心的现行说明。

## 可测试的假设

| 假设 | 如何执行 | 观察指标 |
| --- | --- | --- |
| 具体标题更容易让目标读者识别主题 | 在准确表达承诺的候选标题中比较；保持关键词自然 | 打开率，记录曝光分母和样本量 |
| 前两行说明内容价值有助于继续阅读 | 明确问题、对象和收益，避免虚假悬念 | 停留、完读或可获得的替代指标 |
| 实用内容更容易被保存 | 用具体步骤、对比、证据或清单表达 | 收藏/曝光、实际反馈 |
| 真实开放的问题促进有意义讨论 | 提问与正文经验相关，不用福利诱导 | 评论质量与回复内容 |
| 准确关键词帮助检索 | 自然出现在标题、正文和相关标签中，不堆词 | 搜索来源及匹配查询（仅当平台提供） |

不对点赞、收藏、转发、评论或关注指定假想算法权重；缺失曝光/关注等字段时标 missing，不反推。

## 实验边界

- 图片数量严格服从 `seednote_image_mode` 与 1–3 张内容图规划，不为猜测算法额外生图。
- 字数服从用户锁定内容和写作 Skill 的交付限制，不为猜测“600 字加权”扩写。
- 标签根据内容和目标读者选择；数量建议是编辑启发式，不是曝光门槛。
- 一次比较少量有明确差异的候选，记录样本、时段、受众和混杂因素；不得把相关性说成因果。
- 不保证“进推荐池”“流量归零”或“一定限流”；只报告实际可见证据。
