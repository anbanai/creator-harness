# 卖点可视化与平台口吻

> Anban 业务补充：把排序卖点桥接到视觉符号，并按目标平台调整表达。平台视觉任务与常见坑以上游 `$UPSTREAM_ECOMMERCE_SKILL/references/platform-playbooks.md` 为准；核心卖点与 FABE 不因平台改变。

## 卖点 → 视觉符号桥（给 visual-design 用）

每个排序卖点给出**建议可视符号**，让抽象卖点能在图里可视（这是文案与视觉的桥）：

| 卖点类型 | 可视符号示例 |
|---|---|
| 续航 / 大容量 | 电量条 / 时钟 / 容量柱对比 |
| 轻 / 便携 | 羽毛 / 手持比例 / 与硬币对比 |
| 防水 / 防摔 | 水珠 / IPX 等级标 / 跌落瞬间 |
| 快充 / 速效 | 闪电 / 倒计时 / 曲线 |
| 天然 / 成分 | 原料实拍 / 成分图标 / 提取过程 |
| 保暖 / 透气 | 温度计 / 气流箭头 / 红外热图 |
| 高颜值 / 设计 | 几何线条 / 多角度展示 / 场景融入 |

> 卖点若无可视符号，visual-design 难以图文对应——文案定稿时即标注建议符号，避免「文图脱节」。

## 平台口吻差异化（按 `target_platform`）

同一组卖点，文案口吻按平台调性调整（受众与决策动机不同）：

| 平台 | 口吻 | 偏好 |
|---|---|---|
| **淘宝天猫** | 功能参数 + 价格敏感 | 参数/规格前置、利益直接、促销钩子明确 |
| **京东** | 参数 + 资质 + 服务 | 参数详尽、认证/服务标识、品质信任 |
| **抖音电商** | 情绪冲击 + 短句节奏 | 痛点/反差前置、口语化短句、强代入场景 |
| **种草笔记电商** | 生活方式 + 真实感 | 体验/感受叙事、弱硬广、素人口吻 |
| **微信小店** | 信任背书 + 私域 | 熟人推荐口吻、复购信任、社交亲密感 |
| **通用** | 中性直接 | 不依赖单一平台活动语境 |

> 平台口吻影响主图文案措辞与详情页叙事节奏，但**核心卖点与 FABE 不变**，只换表达；价格/促销/赠品表达必须有任务依据。
