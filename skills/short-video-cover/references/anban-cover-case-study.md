# Anban Cover Case Study

This case study is a calibration reference for the short-video cover workflow.
It is not a template to copy. Read it when a task includes a supplied reference
set or when the current output is text-heavy and lacks a concrete subject.

## Reference Set

The supplied reference covers are stored beside this file:

- [reference-01](examples/resource_20261104_075218.jpg): two identifiable people, a strong two-line question, textured world-building background, and a small identity strip.
- [reference-02](examples/resource_20261104_075221.jpg): one dominant claim, two-person relationship, foreground wave shape, and a compact topic badge.
- [reference-03](examples/resource_20261104_075231.jpg): a real conversational scene, large emotional headline, and a lower name strip.
- [reference-04](examples/resource_20261104_075241.jpg): a visible speaker, a concrete chapter label, and a world-building background that carries the subject.

Across the set, the transferable grammar is:

1. One immediately understandable promise, usually one or two lines.
2. A real person, object, or scene that proves what the promise is about.
3. A background with semantic atmosphere and depth, rather than an empty color field.
4. A small number of stable hierarchy levels: headline, context/series mark, identity or episode label.
5. A restrained palette with one high-contrast accent and clear subject separation.
6. Crop, expression, and overlap that still read at thumbnail size.

## Current Output Diagnosis

`examples/current-output-cover.png` is a useful negative example. It has clean
spacing and legible copy, but it behaves like a typeset poster: no real speaker
or concrete situation, weak semantic evidence for the topic, a long secondary
copy block, large unused areas, and a single dark-gold treatment that makes the
cover easy to overlook in a feed. The chopsticks graphic is an icon, not a
story. The repair is to change the visual argument, not to enlarge every line.

## Transfer Rule

Borrow hierarchy, subject-to-title relationship, depth, and thumbnail behavior.
Replace people, objects, wording, colors, and specific composition so the new
cover is original and grounded in the supplied content.
