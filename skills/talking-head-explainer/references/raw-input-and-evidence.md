# 原始输入与证据

## 输入盘点

按文件而不是按整理后的镜头清单盘点：相机卡全量文件、所有重录版本、独立人声、环境声、room tone、原始转录、录制前提纲、事实资料、数字和案例来源、观众画像、历史发布数据、评论问题与误解、收藏/转发反馈、同主题公开样本。

每项至少记录 `path`、`sha256`、`media_type`、`duration`、`sample_rate`/`dimensions`、`captured_at`（可得时）、`source_role`、`rights_status`、`read_only` 和 `missing_reason`。原始素材只读，任何清洗、代理或拼接都记录为派生文件并保留父级哈希。

## 证据层级

事实主张区分：原始录音/画面、用户提供资料、可追溯公开来源、专家复核、观众理解测试和发布后 Server analytics。前一层不能替代后一层对其专属问题的证明。没有来源时标记 `source_missing`，不要用常识或模型置信度填补。

## 输入完整性

检查是否存在完整录制、连续音轨、可独立转录的语音、足够的环境声、事实来源、观众描述和历史数据。缺少资料仍可编辑，但在 assessment 中区分 `blocking`、`degrading` 和 `unknown`，并把影响写入后续验证范围。
