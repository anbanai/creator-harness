# 选曲、情绪词表与授权核查

本文件是 `video-bgm-design` 第三步和第四步的细则。

## 情绪与能量词表

用同一套词描述章节与曲目，避免“很好听/很高级”这类不可执行判断。

情绪（每段选 2–3 个）：好奇、怀疑、紧张、紧迫、坚定、温暖、亲近、克制、释然、惊喜、兴奋、庄重、怀旧、轻松、孤独、希望。

能量等级：

| 等级 | 特征 | 典型配器 |
|---|---|---|
| 低 | 无鼓或极轻鼓，单声部 | 钢琴、指弹吉他、氛围合成器 |
| 中低 | 轻鼓点、稳定低音 | 电钢琴 + 轻打击 + 低音垫 |
| 中 | 明确节奏、层次清楚 | 鼓组 + 贝斯 + 分解和弦 |
| 中高 | 密集鼓点、推进感 | 鼓组 + 合成器 arp + 弦乐铺底 |
| 高 | 强冲击、强动态 | 重鼓 + 铜管/失真合成器 |

匹配规则：

- 章节 `energy` 与曲目能量差距不超过 1 级。
- 密集口播章节默认不超过“中”；“中高”以上只用于无口播画面段或极短转场。
- 情绪可以“反向支撑”（悲伤段用克制而非悲情），但能量必须匹配。

## 场景选曲样例

| 场景 | 情绪 | 能量 | BPM | 配器建议 | 避开 |
|---|---|---|---|---|---|
| 开场 Hook | 好奇/紧张 | 中 | 90–110 | 轻鼓 + 脉冲低音 | 长 intro、慢起 |
| 干货讲解 | 克制/坚定 | 中低 | 80–100 | 电钢琴 + 轻打击 | 有歌词、密集打击 |
| 案例/数据 | 坚定 | 中 | 95–115 | 稳定鼓点 + 弦乐垫 | 过强旋律抢注意力 |
| 情绪转折 | 释然/希望 | 中低→中 | 85–105 | 钢琴 + 弦乐渐入 | 突然升调 |
| 结尾 CTA | 温暖/坚定 | 中 | 100–120 | 完整鼓组 + 明亮和弦 | 激烈 drop |
| 纯画面/空镜 | 氛围/怀旧 | 低 | 60–90 | 氛围铺底、环境采样 | 明确鼓点 |

## 多曲组合的调性建议

- 相邻曲目优先同调或近关系调（如 C 大调 → G 大调、A 小调 → C 大调）。
- 无法判断调性时，用“同情绪 + 同能量 + BPM 差 ≤ 8%”作为替代判断。
- 三首以上连续换曲时，至少保证首尾两首调性一致，形成闭环。

## 授权核查清单

逐项确认，任一项无法确认即标 `unverified`：

1. 曲目来源：用户提供 / 项目授权库 / CC0 / 免版税订阅 / 单曲购买。
2. 许可证名称与版本（如 CC0 1.0、CC BY 4.0、某平台免版税许可）。
3. 是否允许商用（含商业推广、带货、广告投放）。
4. 是否要求署名；要求的署名文案与位置。
5. 是否限制平台或地域。
6. 是否允许二次剪辑、变速、loop。
7. 文件哈希与来源路径（不写密钥或内部 URL）。
8. 授权有效期（订阅类需要记录订阅状态与到期日）。

常见风险：

- “免费下载”不等于可商用。
- “免版税”不等于“免署名”。
- 平台曲库曲目通常只能在平台内使用，导出到其他平台无效。
- AI 生成音乐需要确认生成服务的使用条款。

## 可替换性（交付给剪辑者）

每条 cue 记录 2–4 个中文检索词，便于日后在剪映等工具中替换：

- 情绪类：悬念、温暖、励志、治愈、紧张、高级感
- 风格类：轻电子、钢琴、弦乐、Lo-fi、国风、氛围
- 节奏类：节奏感、卡点、慢节奏、轻快

检索词必须与曲目实际特征一致，不得堆砌热门词。
