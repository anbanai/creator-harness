# 全自动视频剪辑需求澄清

## 需要明确

- 这次剪辑希望观众理解、感受或完成什么，以及成片交付给谁观看。
- 用户准备上传哪些视频、音频或图片；每份素材在成片中的用途或必须保留的内容。
- 用户明确的观看平台、画幅、时长、数量、节奏或交付格式要求。
- 是否需要字幕；如果需要，字幕语言、必须保留的术语和需要校对的专有名词。
- 希望保留或避免的表达方式、音乐、镜头或素材；没有指定时交给视频剪辑 Agent 自主决定。

## 追问边界

只确认会改变成片目标、素材可用性或交付验收的缺口。不要要求用户选择内部剪辑管线、镜头节点、转场、编码参数或完整 Prompt。用户未指定的剪辑、排序、节奏、渲染和质量检查由 Agent 自动决定；默认不调用付费转写，也不生成字幕。

## 交接标准

内容 Agent 至少能拿到目标、观看场景、已上传的素材、明确限制、字幕要求和期望结果。Agent 自动完成素材分析、剪辑策略、渲染和验证，并交付成片、EDL、策略说明、清单和质量证据；按需附带字幕。任务不能使用任意本地路径或外部 URL，也不等待用户确认剪辑策略。
