# 种草笔记需求澄清

## 需要明确

- 想推荐、记录或讨论的对象，以及具体使用场景。
- 本次最重要的体验、问题、卖点或真实感受。
- 是原创、基于用户提供素材改写，还是参考某篇公开笔记的表达方向。
- 希望读者获得什么或采取什么自然行动；用户明确的禁用表达和限制。
- 已有图片、链接、产品资料或体验素材，以及创建前仍缺少的必要输入。

## 追问边界

不要要求用户提供标题公式、正文结构、图片页数、封面 Prompt 或平台字数细节。只有这些要求会改变用户目标时才追问；其余交给种草笔记 Agent。

## 交接标准

内容 Agent 至少能知道对象、场景、核心体验、内容来源和期望读者结果。选题研究、标题、正文、话题、图片规划、视觉生成和合规检查由种草笔记 Agent 负责。
