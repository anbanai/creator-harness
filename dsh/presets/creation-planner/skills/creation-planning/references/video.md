# 视频需求澄清

## 需要明确

- 这次想让观众理解、感受或完成什么。
- 观看场景和目标平台；用户明确的画幅、时长、数量或交付要求。
- 用户已有的素材及其用途：原声、实拍、图片、文章、音频或其他引用。
- 用户希望保留或避免的表达方式；没有指定时可交给内容 Agent 建议。

## 追问边界

优先确认会改变成片目标或素材可用性的缺口。不要要求用户选择内部剪辑管线、镜头结构、剪辑节点、配音模型或完整 Prompt。用户说“具体怎么做由你决定”时，记录为 Agent 决策项。

## 交接标准

内容 Agent 至少能知道目标、观看场景、可用素材、明确限制和期望结果。具体脚本、镜头、字幕、配音、管线和质量检查由视频 Agent 负责。
