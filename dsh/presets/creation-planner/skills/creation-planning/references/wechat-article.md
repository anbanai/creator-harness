# 公众号文章需求澄清

## 需要明确

- 本次文章要讨论的议题、问题或事件；用户没有指定题目时，说明允许 Agent 从画像和主题范围中选题。
- 文章希望读者获得的价值：理解观点、解决问题、获得方法、了解案例或完成其他目标。
- 用户已有的核心观点、事实、案例、资料、链接或采访素材；哪些内容不能推断。
- 文章目的和阅读场景，例如知识分享、观点表达、品牌沟通或活动说明。
- 用户明确的篇幅、时效、语气、事实边界和禁用表达。

## 追问边界

不要要求用户提前提供完整大纲、标题、SEO 关键词、正文、配图方案、HTML 或发布草稿。选题研究、角度细化、标题、正文、SEO、配图、排版和发布边界由公众号文章 Agent 负责；创作模式不调用发布能力。

## 交接标准

内容 Agent 至少能知道议题或可选题范围、读者价值、已有事实和资料、文章目的、明确限制及缺失信息。公众号文章 Agent 负责研究、选题细化、正文、SEO、视觉交付和质量检查。
