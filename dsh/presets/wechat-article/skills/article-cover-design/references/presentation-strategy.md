# 封面呈现方式决策

封面概念和呈现方式是两个独立决策：概念决定“读者要看到什么冲突或证据”，呈现方式决定“用什么视觉语言让它在缩略图里被看懂”。先选概念，再选择最能放大该概念的呈现方式；不要把每篇文章都做成无字静物摄影，也不要把第二张参考图的排版形式硬套到所有主题。

## 可选呈现方式

从下面的方向中选择最合适的一种，必要时使用克制的混合方式。名称是决策标签，不是固定模板。

| 方式 | 适合的内容信号 | 主要视觉锚点 | 常见失败 |
| --- | --- | --- | --- |
| `editorial-cover` 编辑封面 | 标题有强冲突、反差、数字、判断或栏目感 | 清晰标题层级 + 一个具体证据物/图形 | 标题塞满画面，图像只剩装饰 |
| `documentary-photography` 纪实摄影 | 真实场景、人物故事、物件关系本身就能说明问题 | 一个可信的场景或主体关系 | 变成泛办公/生活方式库存图 |
| `conceptual-illustration` 概念插画 | 抽象观点需要象征，但仍有可画的具体关系 | 一个夸张、可辨认的视觉隐喻 | 只剩漂亮氛围，换文章也成立 |
| `diagrammatic-explainer` 图解封面 | 对比、流程、数量、前后变化是核心承诺 | 结构化对比、箭头、少量准确标签 | 变成 PPT 拼图或伪数据海报 |
| `hybrid-editorial` 克制混合 | 摄影/插画主体需要标题或少量数据标签才能快速读懂 | 主媒介主体 + 有秩序的编辑排版 | 风格堆叠，主体和文字互相争夺注意力 |

## 选择规则

1. 如果标题本身包含读者必须立即理解的冲突、数字、前后关系或判断，优先评估 `editorial-cover` 或 `diagrammatic-explainer`；图上文字可承担信息气味，但只使用从标题、摘要或正文证据准确摘取的短文本。
2. 如果文章的可信度来自一个具体场景、人物动作或物件关系，优先评估 `documentary-photography`；让场景证据承担解释，不要额外加无关标签。
3. 如果文章是抽象认知或方法论，先寻找正文中可验证的隐喻；只有隐喻能在缩略图里形成明确关系时，才使用 `conceptual-illustration`，否则回到编辑封面或图解。
4. 如果读者需要看懂“多/少、涨/跌、前/后、A/B、输入/结果”，优先评估 `diagrammatic-explainer`，但控制为一个主对比，不做多卡片仪表盘。
5. 若项目已有 `visual_style`，把它当作色彩、材质和品牌语汇的边界；不要让它覆盖当前文章更合适的版式或媒介。
6. 没有明确理由时，不添加文字；但“担心乱码”不是删除文字的理由。若文字是缩略图理解冲突的最低成本，宁可减少字数、限定逐字白名单和层级，再进行审核。

## 计划字段

在 `cover_strategy` 中记录：

```json
{
  "selected_visual_treatment": {
    "mode": "editorial-cover|documentary-photography|conceptual-illustration|diagrammatic-explainer|hybrid-editorial",
    "why_this_mode": "它如何放大选中概念并帮助目标读者在缩略图读懂承诺",
    "primary_anchor": "标题、主体关系或对比结构中的唯一第一视觉锚点",
    "secondary_evidence": ["只保留确实增强承诺的证据"],
    "text_policy": "none|short-label|headline-and-subtitle|labeled-comparison",
    "visible_text_whitelist": [],
    "reading_order": ["first", "second", "third"]
  }
}
```

`primary_anchor` 只能有一个。`secondary_evidence` 是可删减的，不要把候选阶段列出的所有物件都写成必须出现。若使用图中文字，`visible_text_whitelist` 必须逐字列出；模型不得自行补充数字、汉字、logo 或伪文字。

## Prompt 编译与审核

最终 prompt 先写“读者在 0.5 秒内要读懂的关系”，再写主视觉锚点、阅读顺序、版式/构图和文字白名单，最后补颜色、质感和媒介细节。对编辑封面，描述网格、留白、标题层级、字图比例和边缘；对摄影，描述场景可信度、镜头和光线；对插画，描述形状、线条和色块；对图解，描述一个明确的关系和标签位置。

独立审核时缩小到实际分享卡大小，检查第一眼是否有单一锚点、标题/主体关系是否清楚、文字是否逐字准确、画面是否像完成的封面而不是生成草图。若不通过，先修正呈现方式、层级或主锚点，再调整修饰性风格词。
