## 尾图的唯一使命

尾图是用户滑完所有内容后的最后一屏。它不新增事实，只做内容相关的温和收束或站内互动提示；根据内容主题自动匹配。

---

## 自动匹配规则

| 内容类型 | 匹配尾图类型 | 判断依据 |
|----------|------------|----------|
| 知识干货、教程、合集 | **关注**（follow） | 用户想持续获取同类内容 |
| 测评、对比、好物推荐 | **评论**（comment） | 用户有观点想表达，评论自然度高 |
| 种草、好物分享、品牌推荐 | **站内收束**（traffic） | 只做与本篇内容相关的站内检索或合集提示，不做交易或私域转化 |

Agent 在 image-plan 阶段根据内容主题自动判断，无需用户指定。

---

## 类型一：内容预告（follow）

**目标**：用已发布内容的后续预告完成温和收束，不要求关注、私信或购买。

**内容策略**：
- 2-3 条前瞻性内容预告（"下期讲XX"、"收藏夹里还有XX"）
- 一句氛围收束语（营造"这只是开始"的感觉）
- 禁止直接说"关注我"、"点关注"、"去主页"

**视觉规范**：
- 文字占比 15-25%，留白 45-55%
- 上/中/下三段式布局
- 适度克制，营造"未完待续"的呼吸感
- 与内容页风格一致但不过度花哨
- 只出现简体中文，不出现英文、拼音、乱码或伪词

---

## 类型二：评论引导（comment）

**目标**：在内容确实适合讨论时，以一个不含关键词或转化要求的开放问题收束。

**内容策略**：
- 一个与笔记内容强相关的开放式问题
- 或一个有争议/讨论空间的观点
- 禁止泛泛的"你怎么看"类问题

**视觉规范**：
- 文字占比 25-35%
- 问题文字居中偏上，视觉焦点集中在问题本身
- 可用对话框/气泡等元素增加互动感
- 风格活泼，但不要求关键词、私信、购买或关注转化

---

## 类型三：站内收束（traffic）

**目标**：只做与本篇内容相关的站内检索或合集提示，帮助读者继续查阅已发布内容。

**内容策略**：
- 站内收束：明确、非商业的站内检索或已发布合集提示（仅在本篇内容已有依据时）
- 收束语与笔记内容自然关联

**安全红线**：
- 禁止二维码、微信号、手机号、外部链接
- 禁止"加微信"、"私聊我"等直接引导词


**视觉规范**：
- 文字占比 20-30%，核心信息居中
- 可用与站内检索相关的放大镜图标；不得使用信封、私信或购买暗示
- 风格克制，避免广告感

## Prompt 模板（v3 - 结构化中文文字渲染）

尾图单独生成，根据匹配类型使用对应的 prompt 结构。生成前先读 [prompt-blueprint.md](prompt-blueprint.md)，只传入 `image-plan.md` 为尾图选中的相关参考图：

```
页面契约：这是种草笔记信息流的尾图，类型为 {tail_type}，页面职责是 {page_goal}；输出比例为 {aspect_ratio}。

文字契约 — 只允许出现以下可见文字，按顺序逐条原样渲染：
{visible_text_whitelist}
禁止补写副标题、标签、品牌名、页码、水印或伪词。文字安全区为 {text_zone}，保证缩略图可读。

构图地图：{camera}，{shot}；第一视觉焦点是 {focal_area}；{layout_map}；保留 {negative_space}；阅读顺序为文字 → {visual_anchor}。
艺术指导：{medium_and_surface}；共享风格锚点为 {style_anchors}；本页保持克制，避免广告感。
光线与质感：{lighting}；主体细节为 {material_details}。

禁止项：任何英文字母、拼音、阿拉伯数字、乱码、伪词、二维码、微信号、手机号、外部链接、与正文无关的季节/品类/产品和模糊养生承诺；不得带入正文其他页面的整套文案。

{tail_type_specific_instructions}

输出验收：{acceptance_criteria}；无水印、无额外文字，尾图与整组风格一致但不复制封面或内容图的整套构图。
```

```
- 文字占比 15-25%，留白 45-55%，呼吸感
- 上/中/下三段式布局
```

### 评论型 tail_type_specific_instructions

```
尾图目的：内容讨论收束
- 一个与笔记内容强相关的开放式问题
- 问题居中偏上，视觉焦点集中在问题
- 文字占比 25-35%，可用对话框/气泡元素
- 风格活泼，但不要求关键词、私信、购买或关注转化
```

### 站内收束型 tail_type_specific_instructions

```
尾图目的：站内收束（{traffic_direction}）
- {traffic_direction}：仅限与本篇内容相关的站内搜索或已发布主页合集
- 收束语与笔记已出现的内容自然关联
- 禁止私域导流、购买引导、评论关键词、私信暗示和关注转化话术
- 文字占比 20-30%，核心信息居中
- 仅可用与站内检索相关的放大镜图标；禁止信封、私信或购买暗示
- 绝对禁止：二维码、微信号、手机号、外部链接
```

## 生成方式

通过 MCP 工具调用 `generate_image`，传入尾图在 `image-plan.md` 中选定的参考子集（没有相关参考时才使用纯文生图），输出固定命名为 `tail.png`。

> **关键规则**：尾图单独生成，不使用批量模式。
